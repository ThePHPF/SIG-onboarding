# The Onboarding Initiative for PHP

## Overview
The Onboarding Initiative is one of the Special Interest Groups facilitated by The PHP Foundation. 

### Mission
This group aims to improve the experience of newcomers to the PHP language. It includes the ways they learn the language and the ways they connect with the community.

### How to Join

There will be a kick-off meeting **August 24, 2026 at 13:00 UTC**. To get an invite to this meeting, register your interest using [this form](https://docs.google.com/forms/d/e/1FAIpQLSebw6h2OE-yvkUUkZsvPmYaix8WxHgmeFsZB16mi83-cAKFFA/viewform?usp=preview).

### Code of Conduct
By participating in this Special Interest Group, you are agreeing to adhere to [The PHP Foundation Code of Conduct](https://thephp.foundation/code-of-conduct/), so make sure you have read and understand our expectations for behavior in this space. :heart:
